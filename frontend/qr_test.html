Hệ thống AgriTrace - Kiểm thử sinh mã QR (Task S-46)

Kiểm tra tạo mã QR từ URL truy xuất nguồn gốc hoặc mã định danh lô hàng, hiển thị ảnh Base64, Streaming PNG và Vector SVG.

📦 1. Sinh mã QR cho lô nông sản (Batch ID)

API: GET /batches/{batch_id}/qr (gắn URL truy xuất công khai /#trace?batch=...)

Kích thước tem nhãn: 3.0 cm x 3.0 cm (S-46)
Tải ảnh PNG Tải file SVG

⚙️ 2. Sinh mã QR từ chuỗi dữ liệu tùy biến

API: POST /batches/qr/generate hoặc GET /batches/qr/generate

Tải ảnh PNG

🌐 3. Kiểm tra nhúng StreamingResponse trực tiếp vào thẻ HTML <img>

Browser trực tiếp gửi GET request tới backend và nhận về byte stream ảnh PNG với Content-Type image/png:

URL gọi trực tiếp:
http://127.0.0.1:8000/batches/qr/generate?data=AgriTrace-DirectStream-Test&format=png&box_size=8 ✓ StreamingResponse (image/png)
