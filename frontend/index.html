1. Quản lý vùng trồng

Thêm và sửa vùng trồng ngay tại form; nút Xoá chỉ hiện với tài khoản admin (farmer gọi API xoá sẽ nhận 403 Forbidden).

POST /farms GET /farms PUT /farms/{id} DELETE /farms/{id}

Danh sách vùng trồng

ID Tên vùng trồng Địa điểm Diện tích (ha) Chủ sở hữu Thao tác

Chưa có vùng trồng nào. Hãy thêm ở form phía trên.

2. Quản lý lô nông sản

Tạo và sửa lô nông sản của một vùng trồng; nút Xoá chỉ hiện với tài khoản admin.

POST /batches GET /batches GET /batches/{id} PUT /batches/{id} DELETE /batches/{id}

Danh sách lô nông sản

ID Vùng trồng Tên sản phẩm Số lượng (kg) Ngày thu hoạch Thao tác

Chưa có lô nông sản nào. Hãy tạo ở form phía trên.

Tài khoản hệ thống admin

Chỉ admin xem được mục này; farmer gọi API sẽ nhận lỗi 403 Forbidden.

GET /users

ID Tên đăng nhập Vai trò (role)

Chưa có tài khoản nào.

3. Lịch sử thao tác admin

Ai đã làm gì trong hệ thống: mỗi thao tác tạo/sửa/xoá vùng trồng hoặc lô nông sản thành công được ghi lại 1 dòng. Chỉ admin xem được mục này; GET /audit-logs gọi bằng farmer sẽ nhận 403 Forbidden.

GET /audit-logs

Log mới nhất hiển thị trước · thời gian theo giờ máy (backend lưu UTC — rê chuột lên ô Thời gian để xem giá trị gốc)

Danh sách thao tác

ID Thời gian Người thực hiện Hành động Đối tượng ID dữ liệu

Chưa có thao tác nào được ghi nhận. Hãy tạo/sửa/xoá vùng trồng hoặc lô nông sản rồi bấm Tải lịch sử thao tác.

Dữ liệu lấy từ backend http://127.0.0.1:8000/docs · Chạy backend: uvicorn app.main:app --reload

Đăng nhập demo: admin / 123456 (admin) · farmer / 123456 (farmer) · API: POST /auth/login — xác thực HTTP Basic, không dùng JWT

CRUD: POST/GET/PUT/DELETE cho /farms và /batches · xoá dữ liệu chỉ dành cho admin (farmer nhận 403 Forbidden)

Lịch sử thao tác: GET /audit-logs — chỉ admin xem được (farmer nhận 403 Forbidden) · log tự ghi khi tạo/sửa/xoá /farms, /batches
